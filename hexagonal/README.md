# Hexagonal Architecture (Ports & Adapters)

Ціль архітектури — повна незалежність бізнес-ядра (`core`) від інфраструктури (бази даних чи файлової системи). Адаптери можна легко перемикати через змінні середовища[cite: 9].

## Структура:
- **`core/`** — доменні сутності, порти (інтерфейси) та сценарії використання (use cases).
- **`adapters/`** — зовнішні реалізації (Postgres DB, CSV файл, HTTP контролери).
- **`config/`** — фабрика для впровадження залежностей (DI) залежно від `REPO_ADAPTER`.
