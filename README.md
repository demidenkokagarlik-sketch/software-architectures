# Architectural Patterns Project

Цей репозиторій містить реалізацію чотирьох популярних архітектурних патернів та підходів на базі Python (FastAPI) та Docker:

1. **`layered-monolith/`** — Класичний багатошаровий моноліт з чітким розділенням на шари: Presentation, Application, Domain, Infrastructure.
2. **`hexagonal/`** — Гексагональна архітектура (Ports & Adapters) з ізольованим доменним ядром та можливістю перемикання адаптерів (Postgres / CSV) через змінні середовища.
3. **`microservices/`** — Мікросервісна архітектура (сервіси `catalog`, `users`, `orders`) із єдиною точкою входу через NGINX API Gateway.
4. **`event-driven/`** — Подіяльно-орієнтована архітектура з асинхронною взаємодією сервісів через брокер повідомлень Apache Kafka та Zookeeper.

## Запуск
Кожна папка є повністю незалежним проєктом. Для запуску конкретної архітектури перейдіть до відповідної папки та виконайте:

docker compose up --build
